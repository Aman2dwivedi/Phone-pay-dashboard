# 📊 PhonePe Data Analysis Dashboard

### 📈 Business Intelligence • Transaction Tracking • Visual Analytics

This project features a comprehensive, interactive 5-page Power BI dashboard designed to mirror real-world business scenarios. It analyzes granular PhonePe transaction data, tracks payment success rates, and provides deep-dive visualizations into multiple digital services, offering actionable insights for data-driven decision-making.

### 🚀 Key Features & Insights
*   **Executive Overview:** A centralized homepage summarizing total transaction volumes, success rates, and overall platform performance.
*   **Failure Diagnostics:** Dedicated visual tracking of failed transactions to instantly identify root causes such as server errors, wrong payment details, or insufficient balances.
*   **Service-Specific Analytics:** Granular deep dives comparing revenue and volume across individual services (Insurance, Loans, Money Transfers, and Recharges).
*   **Dynamic Interactivity:** Integrated time-intelligence slicers allowing users to filter data by specific date ranges, updating all KPIs seamlessly in real-time.
*   **Brand-Aligned UI/UX:** A highly customized interface utilizing PhonePe’s signature purple color palette, intuitive page-navigation buttons, and polished charting aesthetics.

---

### 🏗️ Dashboard Architecture 

The report is structured into 5 interconnected pages for seamless, app-like navigation:

1.  **🏠 Homepage:** Macro-level metrics, total transaction amounts, and dynamic date-range filtering.
2.  **🛡️ Insurance Payments:** Categorized breakdown of term life, car, and health insurance premiums.
3.  **💸 Loans:** Repayment tracking and volume analysis across auto and personal loans.
4.  **🔄 Money Transfers:** P2P (Peer-to-Peer) and bank transfer volume monitoring.
5.  **📱 Recharge & Bills:** Usage insights into mobile recharges, DTH, and utility bill payments.

---

### 🗂️ Dataset Overview

The underlying data model processes complex transaction records, encompassing:
- **User Demographics:** User IDs, Names, Ages, and Join Dates.
- **Transaction Metrics:** Transaction IDs, Transaction Amounts, Dates, and Payment Statuses (Success/Failure).
- **Service Categories:** Granular tags for UPI transfers, EMIs, insurance types, and recharge methods.
